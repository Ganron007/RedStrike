Two ways to use RedStrike:

1. **Standalone (this repository)** — you bring your own lab, graph, and seed. See SETUP.md.
2. **CADRE Plan 01 (integrated pin)** — campaign operators install from `CADRE/tools/red-strike/`. Graphs and scripts stay in CADRE. This public repo does not ship lab credentials.
